# Your method

How your sales team thinks. Every agent reads these four files before any task, so the team works your way, not a generic way. Each comes with a short starter. Replace it with your own whenever you're ready: paste in your own framework, or tell the strategist how you think and have it draft the file for your yes.

| File | What it holds |
|---|---|
| [buyer-lens.md](buyer-lens.md) | The questions you ask about every buyer. Every ICP, offer, message and report carries a read through this lens |
| [strategy.md](strategy.md) | The choices every business must answer, in order. Each business pack is organized by them |
| [evidence.md](evidence.md) | How you rate a claim, and when a number is big enough to act on |
| [house-rules.md](house-rules.md) | Your own rules for selling: channels you won't use, promises you won't make, how you write |

One more file, read whenever a job involves math: [calculations.md](../team/calculations.md), the exact methods for scoring, freshness, deduping, back-tests, tallies, forecasts and growth-report numbers, and the CSV formats they read. It's how the team gets exact numbers without shipping any code.

Change a method file the same way as any rule: a dated file in `decisions/` with the reason, then the file itself.
