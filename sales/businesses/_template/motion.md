# Motion (cascade choice 4: capabilities)

- **Motion(s):** PLG, MLG, SLG, customer-led, or a blend.
- **Motion repo(s) and version:** the add-on to open with this repository, and the version in its `VERSION` file.
- **Scorecard:** the latest score of the business against the motion's best practice (date, motion repo version, lowest items).
- **Why this motion:** how buyers like this one prefer to buy, with the Lens read lines that point to it.
- **If blended:** which motion owns which buyers and stages, so no buyer gets two sequences.
- **What it changes for the core team:** filled from the motion repo's `motion-template.md`.
- **Stages:** the default [pipeline stages](../../playbooks/pipeline-stages.md), or the motion's own.

Until the motion repo exists, the core team runs on its own playbooks and this file says "core only".
