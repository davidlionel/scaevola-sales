# Plays

A play is one targeted test: one buyer, one trigger, one message angle, with counts that confirm or kill it, set before anything is sent.

Copy [_play-template/](_play-template/plan.md) to `plays/YYYY-MM-DD-short-name/`. Each play holds:
- `plan.md`: the sales manager's plan.
- `list.md`: the prospector's list.
- `drafts.md`: the outreach drafts.
- `tally.md`: the pipeline agent's count.
